# Accessibility audit: Atropos (2026-10-28, pre-production)

> Spot check of the RGAA 4.1.2 criteria that can be verified in the code. It is not a full RGAA audit and gives no conformance rate.

Scope: `src/renderer/` (desktop app) and the band of the Claude Code mod (`src/mod/`).

## Legal obligation

None: personal open-source project, neither a public body nor a service covered by the European Accessibility Act. Accessibility is a deliberate practice; no accessibility statement is required.

Compliant: 20 · Non-compliant: 6 (all fixed) · To check by hand: 6

## Compliant

- Images (1.1, 1.2): logo, Greek key divider, ring and sidebar icons are `aria-hidden`; the chart has `role="img"` and a description pointing to the table.
- Complex image (1.6): the chart has a table alternative in a `<details>`; the hover-only Recharts tooltip adds nothing the table lacks.
- Colours (3.1): usage levels are written as text next to the colour; the band's pace delta carries a +/− sign.
- Contrast (3.2, 3.3): every text and graphic pair is checked in both themes by `theme-contrast.test.js`, including focus and status pills.
- Language (8.3, 8.7): `lang` follows the chosen language; each language option carries its own `lang`.
- Headings (9.1): one `h1`, then `h2` per view and `h3` per card, no skipped level.
- Lists (9.3): navigation and steps are `<ul>` / `<ol>`; figures are `<dl>`.
- Data table (5.x): `<caption>`, `th scope="col"` and `scope="row"`.
- Gauges and dates: `<meter>` with a `<label>`, `<time datetime>`.
- Scripts (7.1, 7.3): native buttons, links, `select`, `details`; `aria-current` on the active view; no `onClick` on a non-focusable element.
- Status messages (7.5): `role="status"` for results, `role="alert"` for errors.
- Focus (10.7): global `:focus-visible` outline, contrast tested.
- Hidden content (10.8): `.visually-hidden` for the five-hour meter; no `aria-hidden` on focusable content.
- Motion: transitions and animations disabled under `prefers-reduced-motion: reduce`.
- Forms (11.1, 11.2, 11.5, 11.10): every field labelled with `htmlFor`; radios in `fieldset` + `legend`; the error names the expected range, sets `aria-invalid` and is linked by `aria-describedby`.
- Buttons (11.9): every button has a text label.
- Tab order (12.8): no positive `tabindex`; DOM order matches the visual order.
- New windows (13.1): external links open only on user action.
