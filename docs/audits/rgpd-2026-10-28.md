# GDPR audit: Atropos (2026-10-28, pre-production)

> Spot check based on the CNIL developer's GDPR guide. It does not replace a lawyer, a DPO or a certified audit.

Scope: desktop app (`src/main/`, `src/preload/`, `src/renderer/`), Claude Code mod (`src/mod/`), status line (`src/statusline/`), packaging.

## Framework

Everything stays on the user's computer. The publisher collects and receives nothing; the only data is the user's own Claude usage, processed on their machine.

## Not applicable

- B (legal basis) and E (rights): no processing by the publisher and no accounts. Access and deletion are local (History view, Clear history).
- G (processors): none, no data leaves the computer.
- H (legal pages): no website; the README "Privacy" section informs the user.

## To check

1. Information inside the app: the privacy policy lived only in the README. **Done:** a privacy note in Settings → About.
2. Uninstall: `%APPDATA%\Atropos` (database, Chromium cache) stayed after uninstall. **Done:** `deleteAppDataOnUninstall: true` (skipped on updates by electron-builder); the README says `%USERPROFILE%\.atropos` is to be deleted by hand.
3. Journal without the app: when the mod or status line run but the app never does, the `.atropos` journal grows without purge (about 15 MB a year). Edge case, left as is.
4. No network traffic: confirm once with Windows Resource Monitor (Network tab) while the app runs. The code makes no request, but Chromium itself is not audited here.
